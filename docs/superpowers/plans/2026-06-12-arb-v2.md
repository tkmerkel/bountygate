# Arbitrage Detection v2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rewrite the archived arb DAGs against the post-pivot data model, expanded to
sportsbook×sportsbook AND sportsbook×prediction-market arbs for game lines + player props,
plus four experimental web views.

**Architecture:** Spec at `docs/superpowers/specs/2026-06-12-arb-v2-design.md` (read it
first; decisions D1–D10 are binding). Props ride ingest → `raw_market_snapshots` →
normalize → new `player_props_odds_history`. A new pure package
`app/shared/python/bountygate/arb/` holds detection math; `build_arbs` DAG upserts into
`arb_opportunities` (hash PK, first/last-seen lifecycle). Detection-only: **zero** writes to
any `bg_*` legacy table or `arbitrage_executor/`.

**Tech stack:** Python 3.12 (`py -3.12`, pytest from repo root), Airflow 3.2 in Docker (DAG
import checks CONTAINER-ONLY: `docker exec airflow-airflow-scheduler-1 airflow dags
list-import-errors`), Postgres + pg_partman, FastAPI dual-dialect routers, Next.js 16 +
recharts ^3 (NEVER 2.x), Playwright e2e.

**Conventions:** pure functions + dict rows (no pandas) in `bountygate/`; `_db`
orchestrators build engines from `os.environ["DATABASE_URL"]` with `postgres://` →
`postgresql+psycopg2://` normalization; DAG files are thin wrappers; Discord via
`bountygate.utils.discord_notify.notify(msg, level="warning")`.

```python
import math, os

def kalshi_taker_fee(price: float, contracts: int = 1, rate: float | None = None) -> float:
    """Kalshi taker fee in dollars, ceiling-rounded to the cent (conservative for detection).
    fee = ceil_cent(rate * C * P * (1-P)). Source: <cite + date>. Rate env BG_KALSHI_FEE_RATE."""
    r = rate if rate is not None else float(os.getenv("BG_KALSHI_FEE_RATE", "0.07"))
    raw = r * contracts * price * (1.0 - price)
    return math.ceil(raw * 100.0) / 100.0

def venue_effective_cost(price: float, venue_key: str) -> float:
    """Cost to acquire $1 of payout: ask + taker fee. Polymarket has no trading fee."""
    if venue_key == "kalshi":
        return price + kalshi_taker_fee(price)
    return price

def book_venue_roi(book_decimal: float, venue_ask: float, venue_key: str) -> tuple[float, float]:
    """(roi_pre_fee, fee_adjusted_roi) for $1 normalized payout. Arb iff fee_adjusted_roi > 0."""
    t_pre = 1.0 / book_decimal + venue_ask
    t_fee = 1.0 / book_decimal + venue_effective_cost(venue_ask, venue_key)
    return (1.0 / t_pre - 1.0, 1.0 / t_fee - 1.0)
```
